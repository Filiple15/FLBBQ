Minha sugestão para o projeto da FLBBQ

Como vocês já utilizam a Loja Integrada como plataforma principal, eu faria o site da FLBBQ como um front-end personalizado que consome a API da Loja Integrada. Assim, você ganha total liberdade para criar um visual único, filtros avançados, animações e uma experiência de compra diferenciada, enquanto continua aproveitando toda a infraestrutura da Loja Integrada para catálogo, estoque e processamento dos pedidos. É uma arquitetura mais simples de manter e evita duplicar informações entre dois sistemas.
